# Stamps Mini Test

This repository contains my solutions for the Stamps Junior Software Developer mini assessment.

## Tasks

### Task 1 – FooBar
A JavaScript program that generates numbers from 1 to 100, excludes prime numbers, replaces multiples of 3 and 5 with the required text, and prints the results in descending order.

See the [`task-1`](./task-1/) folder for the source code, output screenshot, and instructions.

### Task 2 – Jakarta Weather Forecast
A JavaScript program that retrieves the 5-day weather forecast for Jakarta using the OpenWeatherMap API and displays the average temperature for each day.

See the [`task-2`](./task-2/) folder for the source code, output screenshot, and instructions.
