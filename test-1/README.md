# Task 1 – FooBar

A JavaScript program that generates numbers from 1 to 100, excludes prime numbers, and replaces multiples of 3 and 5 with the required text.

## Requirements
- Excludes prime numbers.
- Replaces multiples of 3 with `Foo`.
- Replaces multiples of 5 with `Bar`.
- Replaces multiples of both with `FooBar`.
- Prints the results in descending order, horizontally.

## How to Run

```bash
node foobar.js
```
